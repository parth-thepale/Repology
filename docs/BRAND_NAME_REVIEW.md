# Repology — Brand and Name Risk Review

**Status:** Blocking review required before public launch  
**Reviewed:** 17 October 2026  
**Decision owner:** Project maintainer

## Finding

The requested name **Repology** is already used by an established open-source project that monitors and compares software package versions across many package repositories.

- Official website: https://repology.org/
- Official GitHub organization: https://github.com/repology
- Example official source repository: https://github.com/repology/repology-updater

This proposed product is different: it helps people understand an individual public GitHub repository, locate key files, inspect setup evidence, and find contribution entry points. However, the same exact name is a meaningful collision even when product purposes differ.

## Risks

1. **User confusion:** people may assume the new tool is part of the existing service.
2. **Search discoverability:** results for the established project may dominate searches for the new product.
3. **Repository and social namespace conflicts:** handles and URLs may be unavailable or misleading.
4. **Legal and brand risk:** documentation alone cannot establish trademark or naming rights.
5. **Launch credibility:** a name collision discovered after promotion can force an avoidable rebrand.

## Required decision before public launch

- [ ] Decide whether to rename to a distinctive alternative. This is the recommended path.
- [ ] Check GitHub organization and repository namespace availability.
- [ ] Check domain and social handle availability.
- [ ] Search relevant trademark registries and obtain qualified advice if needed.
- [ ] Ensure README, package metadata, site title, favicon, social cards, docs, and deployment URLs use one approved name.
- [ ] Avoid statements suggesting any affiliation with the existing Repology service or GitHub.

## Working decision

For document consistency, the project is called **Repology** throughout this draft pack because that is the user's selected working name. It is **not approved for public launch branding** until the above review is completed. This is a product-risk note, not legal advice.
